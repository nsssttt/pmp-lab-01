# Лабораторна робота 01

Програмування мобільних пристроїв. Ресурси і локалізація.

Застосунок показує прізвище студентки, XML-фігуру, прапор і герб. Українська та англійська версії вибираються мовою системи.

## Запуск

Відкрити папку проєкту в Android Studio та запустити `app`. Для збірки потрібні Android SDK 35 і Build-Tools 36.0.0. У Windows також можна виконати `./build.ps1` з налаштованими Java та Android SDK.

Готовий застосунок: [lab01-debug.apk](apk/lab01-debug.apk). Працює на Android 8.0 та новіших версіях.

Java-код і XML-файли містяться в `app/src/main/`.

Відомості про використані зображення наведено в `ASSETS.txt`.
